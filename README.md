## ⚙️ How It Works

1. User clicks the calculator buttons.
2. The clicked value is appended to an expression.
3. The expression is displayed on the calculator screen.
4. When the **=** button is pressed:
   - The expression is evaluated.
   - The result is displayed.
5. **CE** clears the entire expression.
6. **x** removes the last entered character.

## ⚠️ Note

This project currently uses JavaScript's built-in `eval()` function to evaluate mathematical expressions.

For learning purposes this is acceptable, but in production applications it is recommended to replace `eval()` with a custom expression parser for better security and reliability.
